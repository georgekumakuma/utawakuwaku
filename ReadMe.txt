# utawakuwaku　～うたわくわく！～

YouTubeの区間再生プレイリスト／歌枠プレイヤー（Webアプリ／PWA）

---

## ■ アプリの特徴

- 好きなYouTube動画の「ここからここまで」を曲として登録し、プレイリストで連続再生
- 2つのプレイヤーで次の曲を先読みし、クロスフェードで途切れずに切り替え
- 歌枠のコメント欄にあるタイムスタンプ（1:23:45 曲名）を貼るだけで全曲を一括登録
- 評価（★）・アーティスト・タグ・メモ・再生回数・再生履歴
- ライブラリ横断検索、キュー、コマンドパレット（Ctrl+K）、キーボード操作
- スマホやPCで「ホーム画面に追加」→アプリのように利用可能
- 完全ローカル動作・ダウンロード不要・ログイン不要
- プレイリスト（CSV）はテキストエディタで直接編集OK（旧バージョンと互換）

---

## ■ 使い方

1. [https://utawakuwaku.netlify.app] へアクセス
2. スマホなら「ホーム画面に追加」してPWAとして使えます
3. 「＋ 追加」から URL / セットリスト貼り付け / CSV で曲を登録
　　・初回起動時はサンプルが表示されます（ぜひ聴いてみてください！）
　　・「プレイリストバンク」から他のサンプルも読み込めます
4. 設定 → バックアップ（JSON）で別の端末へ引っ越しできます

---

## ■ セキュリティ・注意事項

- 本アプリはYouTube公式APIのみを利用
- 動画ダウンロードや不正な機能は一切ありません

- プレイリスト共有時は、個人情報や非公開URL等を含めないようご注意ください
