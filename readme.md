# 🎵 utawakuwaku v3 〜うたわくわく！〜

YouTube 動画の好きな区間を「曲」として登録し、プレイリストで連続再生する **歌枠のための音楽プレイヤー** です。
歌枠（歌配信）のセットリストをまるごと取り込んで、曲間を途切れさせずに聴けます。

- サーバー不要・アカウント不要・データはすべて自分の端末の中
- YouTube 公式の埋め込みプレイヤーだけを使用（ダウンロードや迂回はしません）
- v1 の CSV・保存データ・共有URL はそのまま読み込めます

設計の背景と今後のロードマップは [docs/VISION.md](docs/VISION.md) を参照してください。

## ✨ v3 の新機能 — 聴く・遊ぶ・眺める

- **シアターモード**（`T` キー / スマホはミニプレイヤーをタップ）— 画面いっぱいの没入型プレイヤー。曲のサムネイルの色で揺らめくオーロラ、文字が浮かび上がるタイトル、進捗リング付きの再生ボタン、傾けて選べる「次の曲」カード。動画は枠へ飛んでいくように移動し、映像オフ時はアートワークをゆっくりパン。スマホでは下スワイプで閉じ、左右スワイプで曲送り
- **アートワーク連動カラー** — 再生中の曲のサムネイルから色を読み取り、アプリ全体のアクセントカラーが曲ごとになめらかに変化（読みやすさは自動で保証、設定でオフ可）。動画の周りには YouTube のアンビエントモードのような光
- **イントロクイズ** — 曲の頭（または曲のどこか）を3〜10秒聴いて、4択で曲名を当てるゲーム。速さとコンボで得点、紙吹雪、ハイスコア、間違えた曲をそのままプレイリストに。キーボードの 1〜4 / Enter / R（もう一度聴く）で遊べます
- **おまかせラジオ** — ライブラリ全体から、評価の高い曲・しばらく聴いていない曲を中心に重み付きで選曲（リンク切れは除外、同じ配信が連続しにくい）
- **配信アーカイブ** — 配信（動画）ごとに、登録した曲を実際の長さのタイムラインで一望。区間をクリックで再生、すき間をクリックでその位置から新しい曲を登録。区間エディタにも同じ配信の他の曲が薄く表示されます
- **どこでも貼り付け・ドロップ** — YouTube の URL・セットリスト・CSV（スプレッドシートからのコピーも可）・共有バンクの URL を、画面のどこに貼っても / ドロップしても、適切な追加画面が開きます
- **ミニプレイヤーのジェスチャー**（スマホ）— 左右スワイプで曲送り、上スワイプ・タップで全画面
- 画面切り替えのアニメーション（View Transitions）

## ✨ v2 の主な機能

### 途切れない再生
- **2つのプレイヤーによる先読み＋クロスフェード** — 次の曲を裏で読み込んでおき、区間の終わりで滑らかに切り替え（秒数は設定で変更、0 で無効）
- 区間終了の二重保険（JS タイマー＋プレイヤー側 `endSeconds`）、曲切替レースの防止、再生エラー時の自動スキップ
- 終了位置を越えてシークしたときだけ自動終了を解除（区間内のシークは終了時間を守る）
- キュー（次に再生）、シャッフル、リピート（全曲 / 1曲 / なし）、再生速度 0.5〜2x
- ロック画面・イヤホン・メディアキーからの操作（Media Session API）

### 曲を集める（3つの方法）
1. **URL を貼る** — 動画タイトル・チャンネルを自動取得。プレイヤーを見ながら **I キー（開始）/ O キー（終了）** で打刻。「保存して次の区間」で同じ動画から続けて切り出し
2. **セットリストを貼る** — コメント欄・概要欄の `1:23:45 曲名 / アーティスト` 形式をそのまま貼ると、全曲が区間付きで一括登録（プレビューで修正可）
3. **CSV / JSON を読み込む** — ドロップ・貼り付け・ファイル選択。同梱の **プレイリストバンク** からも

### 編集
- タイムライン上のドラッグ、±5 / ±1 / ±0.1 秒ボタン、開始・終了の試聴、「最後まで」
- 曲名・アーティスト・歌い手・配信タイトル・タグ・評価（★1〜6）・メモ
- 複数選択（Ctrl / Shift クリック）、ドラッグ並べ替え、右クリックメニュー、削除の取り消し

### 探す・聴き返す
- **ライブラリ** — すべてのプレイリストを横断して検索・並べ替え・タグ絞り込み
- **再生履歴**、再生回数、「よく聴く順」「最近聴いた順」
- **コマンドパレット**（Ctrl/⌘ + K）で曲もコマンドも一発
- **同じ曲の別バージョン** — 曲のメニューから、別の配信で歌った同じ曲をまとめて表示
- **統計** — 日別・時間帯別の再生回数、よく聴く曲、歌い手・アーティスト別の曲数
- **リンク切れチェック** — 削除・非公開・埋め込み禁止になった動画に ⚠ 印（再生エラー時も自動で付く）
- **スリープタイマー**（15〜90分 / この曲の終わりで停止）、**曲ごとの音量補正**、配信タイトルからの**タグ候補**

### 持ち出す
- CSV（旧版互換）、JSON バックアップ（全プレイリスト＋設定）、**共有URL**（圧縮済み・開くだけで取り込み）、YouTube コメント形式のセットリスト

### 見た目
- ダーク / ライト / OS 連動、アクセントカラー、コンパクト表示、映像オフの音声中心モード
- PC は3ペイン、タブレットはパネルがオーバーレイ、スマホはドロワー＋ボトムシート。スマホ縦画面でもシーン名を最優先で表示
- PWA（ホーム画面に追加、UI はオフラインでも起動）

## 🚀 使い方

```bash
# ブラウザで
node server.js          # → http://localhost:3000
# または index.html を静的サーバーで配信（file:// 直接は ES Modules の制約で動きません）

# デスクトップ（Electron）
npm install
npm start
```

初回起動時はデフォルトのプレイリスト（65曲）が読み込まれます。左の「プレイリストバンク」から他のプリセットも追加できます。

### キーボードショートカット（抜粋）
| キー | 動作 |
|---|---|
| Space / ← → | 再生・一時停止 / 前の曲・次の曲（Shift で 10 秒送り） |
| S / R / M / V / T | シャッフル / リピート切替 / ミュート / 映像の表示切替 / シアターモード |
| ↑ ↓ Enter | リスト内の移動・再生（リスト外では音量） |
| E / N / Delete | 編集 / 次に再生に追加 / 削除 |
| I / O | （編集中）再生位置を開始 / 終了に設定 |
| / / Ctrl+K / Q / A / ? | 検索 / コマンドパレット / キュー / 追加 / ヘルプ |

## 💾 データと互換性

- 保存先はブラウザの IndexedDB（使えない環境では localStorage）。v1 の保存データは初回起動時に自動移行されます
- CSV の形式は v1 と同じ `videoId,title,start,end,rating,article`。アーティスト・歌い手・タグ・メモを入力した場合だけ末尾に列が増えます（v1 でもそのまま読めます）
- `end` が空または `start` 以下の曲は「動画の最後まで」再生します（ショート動画の連続再生など）
- 設定 → バックアップで JSON に保存すれば、別の端末・ブラウザへそのまま引っ越せます

### バンク（共有バンク・サンプル）
「バンク」画面には次の3つが並びます。どこから読み込んでも、プレイリストは**あなたのコピー**として追加され、自由に編集できます（元のバンクは変わりません）。

1. **追加した共有バンク** — 他の人が公開したプレイリストの URL を「URLでバンクを追加」で登録したもの
2. **みんなの共有バンク** — 作者が紹介している共有バンク（`playlists/shared-directory.json` で管理）
3. **サンプル（作者のおすすめ）** — アプリに同梱の使用例（`playlists/samples/playlistbank.json`）

#### 共有バンクを公開する（Googleスプレッドシートがおすすめ・サーバー不要）
1. スプレッドシートの1行目に `videoId,title,start,end,rating,article` と入力し、2行目から1曲1行で書く（時刻は `1:23:45` 形式でも可）。このアプリで作ったリストは、プレイリストのメニュー「スプレッドシート用にコピー」で貼り付けられます
2. 「ファイル」→「共有」→「ウェブに公開」→ シートを選び「カンマ区切り形式（.csv）」で公開
3. 表示された URL をアプリの「URLでバンクを追加」に貼り付け、バンクのメニュー「紹介リンクをコピー」で作ったリンクを配る（開いた人はワンクリックで追加できます）

公開した人がシートを直すと、読み込んだ人はプレイリストのメニュー「最新版で更新」で最新の内容を取り込めます（その人がアプリで行った編集は上書きされます）。Googleドライブに置いた CSV ファイルは、Google の制限でブラウザから直接読み込めないため使えません。GitHub・Gist・自分のサイトに置いた CSV / `playlistbank.json` の URL は使えます。

#### 「みんなの共有バンク」への掲載（作者向け）
`playlists/shared-directory.json` の `banks` に `{ "name", "description", "author", "url" }` を追加します。Googleフォームで掲載希望を受け付ける場合は、回答のスプレッドシートに「掲載」列を作って承認した行に ○ を付け、そのシートを「ウェブに公開」した CSV の URL を `sheet` に書きます（○ の行だけが表示されます）。

## 📺 YouTube Premium・広告表示について

このアプリは YouTube 公式の IFrame Player API を使い、実際の `youtube.com` の埋め込みプレイヤーをそのまま表示しています。**広告が出るかどうかは完全に YouTube 側・ブラウザ側の判断**であり、本アプリのコードで制御することはできません。

- 埋め込みプレイヤーは、そのページを開いているブラウザが持つ `youtube.com` の **Cookie（ログインセッション）** を使います。それが有効な Premium アカウントのものなら広告なしで再生されます
- Cookie が送られない場合は未ログイン扱いになり広告が出ます。**キャッシュではなく Cookie の問題**です

**ブラウザ版**: 同じブラウザ・同じプロファイルで Premium にログイン済みなら基本的に広告なしです。「サードパーティ Cookie をブロック」設定・シークレットモード・別プロファイルでは広告が出ることがあります。対処法は Cookie 設定で `[*.]youtube.com` を「常に許可」にすること（Chrome: `chrome://settings/content/cookies`）。`file://` ではなく `node server.js` 経由で開く方が安定します。

**Electron（.exe）版**: 独立したプロファイルで YouTube にログインできず、Google は組み込みブラウザからのサインインをブロックしているため、**仕組み上 Premium でも広告なしにはなりません**。広告なしで使いたい場合は、普段 Premium にログインしているブラウザでブラウザ版を開いてください。
